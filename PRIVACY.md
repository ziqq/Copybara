# Copybara privacy policy

Last updated: 3 November 2026.
This policy covers Copybara for macOS and this website. Developer: Anton Ustinoff. Contact: [a.a.ustinoff@gmail.com](mailto:a.a.ustinoff@gmail.com).

## Clipboard history stays on your Mac

Copybara reads eligible clipboard entries while recording is enabled and stores text, images, rich text and file references locally. History may include the source app identifier, timestamps, copy counts, pinned state and comments. Snippets and preferences are also stored locally. The developer does not receive this content.
Copybara does not require an account and has no cloud synchronization, advertising, analytics SDK or remote crash reporting. It filters recognized concealed, transient and generated clipboard types. This depends on the copying app marking its content correctly; unmarked sensitive content can still enter history. You can pause recording, exclude apps and delete history.

## Accessibility

Accessibility permission enables automatic pasting by sending the paste keyboard shortcut to the application you select. Copybara does not use Accessibility to read screen contents or the contents of other apps. You can revoke permission in System Settings; automatic pasting then stops working.

## Updates and external services

The direct-download build checks for updates on your request through GitHub and uses Sparkle to verify and install them. GitHub receives the network information needed to serve a request, such as your IP address. Clipboard history is not included. Mac App Store builds use Apple's update service and do not contain Sparkle. Those services have their own privacy policies.

## Deletion and support

Use the app's history controls to delete stored clips. Snippets are managed separately in Settings. Removing the app alone may leave its local data on the Mac. If you contact support, the developer receives the information you choose to send; remove private clipboard content from attachments. GitHub issues are public.

## This website

This website is hosted by GitHub Pages. GitHub processes technical request information to operate its hosting service; see [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The website has no analytics, advertising, tracking cookies or third-party scripts. Fonts and product images are served with the site.
The language selector saves only your chosen language in this website's local storage. It does not access the app or its clipboard history. You can clear this preference in your browser's site-data settings. Download, email and support links lead to external services.
