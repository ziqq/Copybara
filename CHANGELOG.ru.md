# Changelog

- [ ] Настраиваемые правила игнора/разрешения по приложениям.

## Unreleased
- **CHANGED**: Введена лицензия Copybara: личное и внутреннее использование в
  компаниях разрешено; распространение и монетизация требуют предварительного
  письменного разрешения. Добавлены подписи автора в файлы репозитория.


## 0.1.2 — 2026-10-03
- **ADDED**: Локализация на английский, русский, немецкий, французский, испанский,
  итальянский, португальский, упрощённый китайский, японский и корейский; язык
  приложения определяется настройками macOS.
- **CHANGED**: Убраны иконки действий в меню; порядок — проверка обновлений,
  настройки, очистить всё. Неоднозначный пункт Clear удалён.
- **FIXED**: Настройки открываются после закрытия меню, в окне с ограниченной
  высотой и прокруткой, без расчёта размера окна по всей форме.
- **FIXED**: Попап сохраняет активным приложение назначения; перед вставкой
  проверяются фокус и разрешение на отправку событий, вставка адресуется этому
  приложению. Изображения доступны в PNG и TIFF для нативных редакторов.


## 0.1.1 — 2026-09-29
- **CHANGED**: Обновлена иконка в меню баре.


## 0.1.0 — 2026-09-24
- **ADDED**: Удаление отдельных клипов мышью — ✕ при наведении и меню по правому
  клику (Paste, Paste as Plain Text, Copy, Pin/Unpin, Delete). Удаление сниппета
  теперь действительно его удаляет.
- **CHANGED**: Попап показывает всю историю (раньше не больше 200 клипов).
- **CHANGED**: Быстрая работа с очень большой историей (замерено на 100 000 клипов):
  попап открывается сразу, поиск идёт в фоне и сужается по мере набора,
  удаление и закрепление не перезагружают список, строки рендерятся страницами
  (`⌘↓` переходит к концу загруженных строк).
- **CHANGED**: Миниатюры картинок уменьшаются и кэшируются; содержимое картинок,
  RTF и файлов загружается только при вставке, копировании или превью.
- **CHANGED**: Предупреждение об Accessibility больше не скрывает действия футера,
  и показывается только системный запрос разрешения (без второго диалога поверх).
- **CHANGED**: DMG называется `Copybara-<version>.dmg`, подписан ad-hoc как
  `dev.ustinoff.copybara` и проверяется после упаковки; локальные сборки можно
  подписывать своей командой из `Config/Local.xcconfig`, чтобы Accessibility
  не сбрасывался при пересборке.
- **FIXED**: Вокруг попапа с Liquid Glass были видны прямоугольные углы.
- **FIXED**: Вставка уходила в сам Copybara, а не в приложение, где вы работали, —
  теперь целевое приложение сохраняется и надёжно получает фокус обратно.
- **FIXED**: Вставка в приложения на Chromium/Electron (Claude, Discord, VS Code, Telegram).
- **FIXED**: Окно Settings не открывалось на macOS 14+; размер истории, срок
  хранения и «Ignore all copies» теперь применяются сразу, статус Accessibility
  обновляется, а «Launch at login» показывает реальное состояние.

- **ADDED**: Плейсхолдеры в сниппетах — `${date}`, `${time}`, `${datetime}`,
  `${clipboard}`, `${uuid}`, раскрываются при вставке; мультистрочный редактор сниппетов.
- **ADDED**: Копирование без вставки — `⌘C` в попапе (и в меню ⌘K) кладёт
  выбранный элемент в буфер и закрывает окно.
- **ADDED**: Сниппеты — переиспользуемые текстовые шаблоны (управление в Settings),
  всегда показываются в попапе и вставляются как обычный клип.
- **ADDED**: Фильтр результатов по типу (All / Text / Images / Files) — цикл по ⌘L;
  активный скоуп показывается пилюлей в строке поиска.
- **ADDED**: Преобразование при вставке из меню ⌘K — Paste Trimmed / lowercased /
  UPPERCASED для текстовых клипов.
- **ADDED**: Срок хранения истории — авто-удаление незакреплённых клипов старше
  7/30/90 дней (или хранить вечно), настраивается в Settings.
- **ADDED**: Проверка обновлений по требованию через GitHub Releases (меню →
  *Check for Updates…*) и релизный workflow по тегу, собирающий и публикующий DMG.
- **ADDED**: Подсказки быстрой вставки ⌘1–9 на первых девяти строках.
- **ADDED**: Футер в стиле Raycast с меню действий (`⌘K`) — Paste, Paste as Plain
  Text, Pin/Unpin, Delete и Clear History, каждое со своим шорткатом.
- **CHANGED**: Дефолтный хоткей открытия теперь `⌘⇧V` (был `⌘⇧C`), как Win+V в Windows.
- **FIXED**: Стрелки перестали навигировать по списку (несут флаги function/numeric-pad);
  выбор и прыжки `⌘↑`/`⌘↓` снова работают вместе с фокусом в поиске.
- **ADDED**: Перетаскиваемый попап с дефолтной позицией в стиле Raycast (по центру,
  в верхней трети); перетащи в любое место — окно прилипает к сетке и открывается
  там, где ты его оставил (режим «Last position»).
- **ADDED**: Переход к первому / последнему элементу по `⌘↑` / `⌘↓`.
- **CHANGED**: Дефолтная позиция попапа теперь «Last position» (была иконка в строке меню).
- **ADDED**: Агент в строке меню, локально записывающий историю буфера обмена
  (текст, изображения, RTF и ссылки на файлы) с дедупликацией по SHA-256 и
  настраиваемым лимитом размера.
- **ADDED**: Поиск-попап с управлением с клавиатуры — глобальный хоткей `⌘⇧V`,
  мгновенный поиск (fuzzy / exact / regex), навигация стрелками, вставка по `↩`,
  вставка без форматирования (`⌥⇧↩`) и быстрая вставка `⌘1`–`⌘9`.
- **ADDED**: Действия над элементом — закрепить (`⌥P`), удалить (`⌥⌫`), очистить
  незакреплённые (`⌥⌘⌫`) и очистить всё, включая закреплённые (`⇧⌥⌘⌫`).
- **ADDED**: Боковая панель превью по наведению или `→` с полным содержимым,
  приложением-источником, временем и счётчиком копирований.
- **ADDED**: Контроль приватности — игнор скрытых/временных типов буфера, чёрный
  список приложений и «игнорировать следующую» (`⌥⇧`-клик) / «игнорировать все»
  (`⌥`-клик) по иконке в строке меню.
- **ADDED**: Настройки — размер истории, порядок сортировки (по последнему / по
  первому / по числу копий), режим поиска, отображение иконки (строка меню / Dock /
  везде), позиция попапа (иконка / курсор / центр), запуск при входе и переключатель
  Liquid Glass.
- **ADDED**: Оформление Liquid Glass на macOS 26 (с возможностью отключения) и
  откат на обычный вибрантный материал на старых системах.
- **ADDED**: Онбординг первого запуска для разрешения Accessibility и иконка
  приложения с капибарой.
- **ADDED**: Непрерывная интеграция (сборка, тесты и выгрузка покрытия в Codecov),
  лицензия MIT и документация (концепт, архитектура, roadmap, релиз, монетизация).
- **CHANGED**: Глобальный хоткей теперь срабатывает по нажатию для надёжного
  первого раза; поле поиска получает фокус сразу при открытии попапа.
- **FIXED**: Попап мог падать или дёргаться из-за рекурсии лэйаута при изменении
  размера окна и панели превью; ресайзы вынесены за пределы прохода лэйаута.
- **FIXED**: Попап мог открываться у Dock, когда иконка в строке меню скрыта;
  позиционирование теперь проверяет якорь и откатывается к курсору.
- **FIXED**: Вставка могла попадать не в то приложение; теперь Copybara ждёт
  возврата фокуса целевому приложению перед вставкой и явно сообщает об
  отсутствии разрешения Accessibility вместо тихого отказа.
